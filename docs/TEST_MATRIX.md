## 10. Limitations

- Token counts are estimates (word-count heuristic, not tiktoken)
- Context savings vary by comment density and code style
- Skeleton mode is strongest for function-heavy code
- C# data classes and flat config files show minimal skeleton savings
- Compressed output is for reading/understanding only
- Diff mode is opt-in and session-local
- Intent filtering is keyword-based, not semantic
- Python skeletonization requires `python3` for best results
